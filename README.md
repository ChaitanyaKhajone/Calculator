## Features

#### Core Navigation & Controls
- **Exit :** Close the application instantly.
- **Clear Functions :** C clears the current entry, while AC resets all calculations.
- **Visual Themes :** High-contrast, color-coded functional buttons for easy navigation.

#### Standard Arithmetic
- **Basic Operations :** Addition, subtraction, multiplication, and division.
- **Quick Toggles :** Percentage (%), decimals (.), and reciprocal (1/x) functions.

#### Advanced Mathematics
- **Powers & Roots :** Square (Sqr), Square Root (Sqrt), and custom exponentiation (Pow).
- **Trigonometry :** Full support for standard (Sin, Cos, Tan) and inverse (ASin, ACos, ATan) functions.
- **Logarithms & Constants :** Built-in Natural Log (Log.e), Base-10 Log (Log.10), Exponential (e.X), and Pi (PI) constant.
-  **Rounding Tools :** Fast precision controls including Ceiling, Floor, Round, and Absolute Value (ABS).
## Technical Overview
- **Interface :** 7x6 grid-style button layout optimized for desktop and mobile layouts.
- **Display :** Large, high-visibility digital output screen at the top.
